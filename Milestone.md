# Current Milestones

Vifx is recentered on one promise: replace Metro bundle production with Vite for React Native and Expo.

The active milestones are tracked in `SPECS.md`:

1. Cleanup and recentering.
2. React Native bundle parity.
3. Expo Vite bundling.
4. Export artifacts without Metro.
5. Dev server proof.

Native build/run workflows, Expo Updates runtime, local Updates serving, response signing, Expo Go, EAS, and full Fast Refresh parity are outside the current product scope.
