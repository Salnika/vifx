# @vifx/expo-config-plugin

Expo config plugin that points the native build scripts generated by `expo prebuild` at the Vifx bundler instead of Metro.

- iOS: exports `CLI_PATH` and `BUNDLE_COMMAND="export:embed"` at the top of the "Bundle React Native code and images" Xcode build phase.
- Android: sets `cliFile` and `bundleCommand = "export:embed"` at the end of the `react {}` block in `android/app/build.gradle`.

Both edits are marker-guarded (`@generated begin/end vifx-bundle-command`), idempotent across repeated `expo prebuild` runs, and preserve user content.

## Usage

```json
{
  "expo": {
    "plugins": ["@vifx/expo-config-plugin"]
  }
}
```

Optional props:

```json
{
  "expo": {
    "plugins": [
      [
        "@vifx/expo-config-plugin",
        {
          "cliPath": "../../node_modules/@vifx/cli/dist/bin.mjs",
          "bundleCommand": "export:embed"
        }
      ]
    ]
  }
}
```
